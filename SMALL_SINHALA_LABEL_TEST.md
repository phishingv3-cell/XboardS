# UI requirement test

- Sinhala mode: every alphabet key is still an English Latin main label.
- A small Sinhala base-letter hint is rendered in green `#07F57E` at the top-right corner of the same key.
- The full key is never replaced by Sinhala text.
- English mode: the small Sinhala hints are hidden; keys remain normal English keys.
- Toolbar/panel buttons are unchanged and do not receive Sinhala hints.
- Key dimensions and row weights remain unchanged.
